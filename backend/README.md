# HousePredict AI — Backend (FastAPI + scikit-learn)

FastAPI service that trains, evaluates and serves the house-price regression pipeline.

## Quick start

```bash
cd backend
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # macOS/Linux
pip install -r requirements.txt

python -m ml.generate_dataset  # sample dataset (skip if you provide data/house_prices.csv)
python -m ml.train             # clean → EDA → train → evaluate → save
uvicorn app.main:app --reload  # serve on http://localhost:8000 (docs: /docs)
```

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | 200 `ok` when the model is loaded, 503 `degraded` otherwise |
| GET | `/api/model-info` | Feature schema, dataset stats, prediction-form definition |
| GET | `/api/metrics` | MAE/MSE/RMSE/R² per model on the held-out test set |
| GET | `/api/analytics` | Chart payloads computed from the real dataset |
| POST | `/api/predict` | Pydantic-validated input → saved pipeline → price |

## Layout

- `app/` — FastAPI application (routes, schemas, services)
- `ml/` — training code: `generate_dataset.py`, `preprocessing.py`, `evaluate.py`, `train.py`
- `models/` — artifacts: `house_price_model.joblib`, `metrics.json`, `model_info.json`, `analytics.json`
- `data/` — `house_prices.csv` (replace with your own CSV of the same schema to retrain)
- `reports/` — Matplotlib/Seaborn EDA images generated by training

## Notes

- The **whole pipeline** (feature engineering → preprocessing → regressor) is one Joblib
  object, so training-time and serving-time preprocessing can never drift.
- Run uvicorn **from the `backend/` directory** so `ml.preprocessing` is importable when
  the pipeline is unpickled.
- Configuration is environment-driven — see `.env.example` (`ALLOWED_ORIGINS`).
- If artifacts are missing, the API boots in a degraded state: `/api/health` reports 503
  and model endpoints return friendly errors — never stack traces.
